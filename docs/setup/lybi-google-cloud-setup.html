Part 1 — Your Lybi identity lybi.ai admin

lybi.ai already runs on Google Workspace (company email). Someone set it up — most likely Netanel. That person is its super admin.

1. Find the lybi.ai super admin you
  • Ask Netanel (and Noa) who set up the lybi.ai email. Whoever it is can sign in at admin.google.com.
  • If you already have a lybi.ai address, try admin.google.com yourself — if it opens the Admin console, you are an admin already: skip to step 3.
2. Create shlomi@lybi.ai and make it super admin lybi.ai admin
  1. admin.google.com → Directory → Users → Add new user → shlomi@lybi.ai.
  2. Open that user → Admin roles and privileges → Assign roles → Super Admin.
Ownership tip: there should be at least two super admins (you and one more), so the company never gets locked out.
3. Sign in as shlomi@lybi.ai and turn on 2-step verification you
  • Google requires it for super admins. Use an incognito window so it doesn't mix with your Boostart login.

Part 2 — Lybi's Google Cloud organization you, as shlomi@lybi.ai

4. Open console.cloud.google.com as shlomi@lybi.ai
  • Accept the terms. Because lybi.ai is a Workspace domain, Google creates the lybi.ai organization automatically.
  • Check: top bar → project picker → you should see lybi.ai as the organization. (If it does not appear within a few minutes: IAM & Admin → Identity & Organization walks you through it.)
5. Allow your Boostart address into the organization
New organizations block outside email domains by default ("domain restricted sharing"). Without this step, adding shlomi@boostart.io fails.
  1. With the lybi.ai organization selected: IAM & Admin → IAM → Grant access → shlomi@lybi.ai → role Organization Policy Administrator (yourself — super admins don't get it automatically).
  2. IAM & Admin → Organization Policies → search "Domain restricted sharing" (iam.allowedPolicyMemberDomains) → Manage policy → Override parent → Replace → Rule: Allow all → Save.
6. Give shlomi@boostart.io admin rights
  • Organization selected → IAM → Grant access → shlomi@boostart.io → roles: Organization Administrator, Project Creator, Folder Admin.
  • That's the address this computer is already signed in with — after this, I can do everything from here.

Part 3 — Billing you, as shlomi@lybi.ai

7. Create the Lybi billing account
  1. console.cloud.google.com/billing → Create account → name Lybi → organization lybi.ai → country Israel → the company card.
  2. Open it → Account management → add shlomi@boostart.io as Billing Account Administrator.
Optional but recommended: Budgets & alerts → a monthly budget (e.g. $200) that emails you at 50 / 90 / 100%.
