# Ofek Development (אופק יזמות) — Real-Estate Developer Demo

## Overview

A demo agent for selling Aspect to residential developers ("קבלנים / יזמים").
Ofek Development is **fictional**: a developer selling apartments off-plan in 5
projects. The data is synthetic, generated by `scripts/seed-realestate-synthetic.js`
— there is no client feed and no reload pipeline.

Same pattern as the BI agents (zer4u / tevanaot): NL question → SQL Generator →
query on the `realestate` schema → analyzed answer, plus Aspect Intelligence on
the same dataset (`/realestate/intelligence`).

**Model:** `gpt-5.6-terra` (overridable via `REALESTATE_CREW_MODEL`)
**Language:** Bilingual — answers in the language of the question; data values are Hebrew

## Data model (`realestate` schema)

| Table / View | What |
|---|---|
| projects, units | the 5 projects and every apartment (building, floor, rooms, type, sqm, direction, view, price, status) |
| leads | ~9.9k inquiries: source, campaign, buyer profile, purchase purpose, budget, rep, first-response time, funnel status |
| activities | ~30k calls / WhatsApp / office visits / quotes / signings per lead |
| deals | ~360 signed contracts: list price, discount, final price, benefit, payment plan |
| campaigns | marketing spend per source and project |
| sales_reps | 8 reps |
| v_project_sellout | sales pace + sell-out forecast per project |
| v_stuck_units | units unsold >180 days with price premium vs comparable sold units |
| v_source_performance, v_campaign_roi | cost per lead / per deal |
| v_rep_performance | response time, conversion, discount above company average (₪) |
| v_segment_benefit | close rate per buyer segment × benefit offered |
| v_call_today | open leads to call today, lead score + Hebrew reason |
| v_deals | deals with the buyer's profile |

SQL rules: `services/schema-rules/realestate.rules.js` (routes questions to the views).

## Findings built into the data (what the demo "discovers")

- Facebook brings the most leads but costs ~₪63K per deal; signage, portals and referrals cost a fraction; Instagram ~₪100K per deal.
- Leads called back within the hour convert ~4x better than after a day. Haifa's conversion fell from ~4.5% to ~1.6% when its slow rep (אלון ברק, median ~23h to first call) took over in May 2026.
- רונן לוי gives ~7.4% average discount vs ~3% company average — ~₪12.8M above average.
- Haifa's 5-room north-facing units were priced ~14% too high: 13 of 14 still unsold after 640+ days while 48 recent leads want 5 rooms. Haifa sells out in ~2029 at today's pace, 21 months after delivery.
- Each segment closes on a different benefit: first home → 20/80 financing (59% vs 11% with parking), investors → price cut (62%), for-the-children → extra parking (60%). Today benefits are offered at random.
- "Buying for the children" grew from ~10% to ~21% of leads.

## Tools

- `fetch_realestate_data` — NL → SQL (shared `DataQueryService`).
- `show_building_board` — deterministic availability board of a project (🟥 sold · 🟨 reserved · 🟩 free · 🟧 free >180 days), one markdown table per building.

## Files

- `agents/realestate/crew/realestate.crew.js`, `crew/index.js`
- `services/db.realestate.js` — re-exports the shared data-DB pool
- `scripts/seed-realestate-synthetic.js` — builds and seeds the schema (`--dry`, `--views-only`)
- `scripts/seed-realestate-agent.js` — inserts the `agents` row ("Real Estate", slug `realestate`)
- `insights/datasets/registry.js` — Intelligence entry (Hebrew report language)

Re-seeding moves the data's end date to the day it runs (dates are relative to today), so re-run the seed shortly before a demo if it has been weeks.
